## 文件上传说明

1. 将 mp3 文件上传至：`web/audio/` 目录
2. **不上传的文件会自动静默跳过**，游戏正常运行，不会报错
3. 配音建议：单文件 ≤ 500KB，采样率 44100Hz，比特率 128kbps
4. 配音内容无需和文本完全一致，口语化、有感情即可
